# Requirements analysis and implementation map

Source: Crest Product Requirements v1.1, dated 18 November 2026, supplied as `Crest_PRD.pdf` (18 pages).

The document defines a Windows 11 utility and a staged roadmap. Its central constraint is desktop-only visibility, including the invisible input region. P0 is the behavioral foundation; P1 is the local first release. P2 adds local refinements and P3 contains later integrations, each requiring its own verification. The application must never represent future API access as already available.

On 19 November 2026, the owner explicitly requested a Settings option to open Crest while another app is active. **Allow Crest over other apps** is the approved exception to the original desktop-only scope. It is off by default; strict desktop remains the starting policy. Enabled access uses the existing hover/controller and optional keyboard shortcut, with Settings, Pause, lock, suspend, and secure-desktop guards retained. Background events still cannot reveal the island.

## P2 local implementation

The visual concurrent-activity overview (part of F15) was selected explicitly through the owner's reference redesign and is included. On 19 November 2026, the owner requested all remaining local F08/F09/F10/F11/F12/F13/F14/F16/F17/F18 functionality. These features are now present in source; existing published packages do not acquire them automatically.

F09 retains eight independent timers and a stopwatch with 100 saved laps. Focus sessions add bounded work/break durations and 1–12 work rounds; completion waits for manual phase continuation, and the final work round finishes the session. Local reminders support relative or local-time scheduling, 5/15-minute snooze, dismissal, and 32 saved entries. Monotonic time governs live elapsed activities; restart recovery uses saved UTC state. Reminders use UTC due times. Completion and due events never reveal Crest. The original timer chime remains opt-in, with an independent preview in Settings → Modules. Earlier owner hearing and installation observations are historical for timer-sound DLL `98C806E9…8BC38991`.

F08 enumerates actual active Windows render endpoints. Explicit switching uses runtime-probed PolicyConfig COM and verifies the default endpoint after the write. PolicyConfig is undocumented and version-dependent; unsupported or failed writes report a problem, and the Windows sound-settings fallback is always available. F11 samples actual total-device CPU, physical memory, and active-adapter network deltas only while Crest is visible and Controls is enabled. F12 reads Wi-Fi/Bluetooth provider state and links to Windows settings; unknown states are not inferred as on or connected.

F10 collection is off by default and requires Settings → Privacy opt-in. It captures only new text clipboard changes, with search/copy/pin/removal, durable pause, clear, and 1–30-day unpinned retention. Limits are 100 entries, 8,192 characters per entry, and 120,000 stored characters. Pins do not expire but remain bounded; clear and disable remove pins too. Enabling, resuming, or clearing does not import the unchanged current clipboard. Retained clipboard text now uses current-user Windows DPAPI protection in 0.3.0, with immediate legacy migration and fail-closed storage recovery.

F13 launches the Windows screenshot tool and keeps up to 12 explicitly selected image paths; it does not monitor screenshot folders. F14 stores up to 20 workspaces with 20 selected app/file/folder/HTTP(S) targets each; one failed target does not stop subsequent launches. F16 saves pinned shelf references and permits explicit replacement selection or opening the nearest existing parent. Unpinned references remain session-only. Original target files are never copied, moved, or deleted by reference management.

F17 stores theme/motion/size/speed and trigger geometry/dwell/grace overrides by display identity. Uncustomized displays use defaults; disconnected selected displays fall back to primary without deleting their profile. Crest still operates on one selected display at a time. F18 adds Ocean/Forest/Rose palettes, Compact/Comfortable/Large size presets, icon-dock ordering, and empty-surface double-click, middle-click, and optional wheel actions. Module order and gestures remain shared preferences.
